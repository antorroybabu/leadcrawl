# LeadCrawl - AI Web Crawling API

The web crawling API built for the AI era. Extract structured data from any website using LLMs — no selectors, no maintenance.

## Features

- **AI-Powered Extraction** - Extract structured data from any website using advanced AI models
- **No CSS Selectors** - Describe what you want in plain English, the AI handles the rest
- **JavaScript Rendering** - Full headless browser support for SPAs and dynamic content
- **Built-in Proxy Rotation** - Automatic proxy rotation and CAPTCHA handling
- **Simple REST API** - Clean API with SDKs for Python and JavaScript

## Getting Started

```bash
npm install
npm run dev
```
